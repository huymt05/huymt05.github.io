# Nguyen Van Huy Personal Website

Personal portfolio website for DevOps / Cloud internship opportunities.

## Deploy With GitHub Pages

1. Create a new public GitHub repository.
2. Recommended repo name: `huymt05.github.io`.
3. Push this folder to the repository.
4. Open the repository on GitHub.
5. Go to `Settings` -> `Pages`.
6. Choose `Deploy from a branch`.
7. Select branch `main` and folder `/root`.
8. Wait for GitHub Pages to publish the site.

If the repository is named `huymt05.github.io`, the website URL will be:

```text
https://huymt05.github.io/
```

For another repository name, the URL will usually be:

```text
https://huymt05.github.io/repository-name/
```
